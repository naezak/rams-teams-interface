## 1. Introduction

The RAMS Microsoft Teams Application provides an interface for accessing OpenText Content Manager (CM) directly within Microsoft Teams.

The application enables authorised users to search, view, and capture records using Content Manager's existing functionality, authentication, and access controls.

By using the application, users agree to comply with these Terms of Use and applicable organisational policies.

The application is intended for users who are authorised to access OpenText Content Manager.

- Comply with applicable laws and records management requirements.

Access to the application does not automatically grant access to records within Content Manager.

Users must not attempt to bypass authentication mechanisms or access records beyond their authorised permissions.
