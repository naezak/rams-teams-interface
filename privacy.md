# Privacy Policy — RAMS Microsoft Teams Application

**Last Updated:** 10 October 2026

## 1. Introduction

The RAMS Microsoft Teams Application provides an interface for accessing OpenText Content Manager (CM) directly within Microsoft Teams.

The application enables users to search, view, and capture records using Content Manager's existing functionality, authentication, and access controls.

## 2. Authentication and Access Control

The application relies on OpenText Content Manager for authentication, authorisation, and record-level access permissions.

The application does not maintain a separate authentication system, manage user credentials, or independently determine record access permissions.

All record-related requests are processed through Content Manager, which validates user access and enforces its existing security policies.

## 3. Information Accessed and Processed

The application may temporarily process information necessary to communicate with Content Manager, including:

- Authentication tokens or related identity information.
- Record metadata, search results, and associated documents.
- Information submitted by users when capturing records.

This information is processed solely to provide the application's intended functionality.

The application does not directly collect or store user passwords and is not intended to maintain a separate permanent repository of Content Manager records.

## 4. Data Security and Storage

The application communicates with Content Manager using secure, approved API integration methods.

Content Manager remains responsible for managing records, enforcing access permissions, and applying established records retention policies.

The application will implement appropriate safeguards for information it processes, including secure communications and handling of authentication information.

Any temporary storage, caching, or logging will be managed in accordance with applicable organisational requirements.

## 5. Third-Party Services

The application uses:

- **Microsoft Teams:** To provide the user interface.
- **OpenText Content Manager:** To authenticate and authorise record access, retrieve records, and manage captured information.
- **Application Hosting Provider:** To deliver the application's web interface and any necessary supporting services.

Information may be exchanged between these systems as required for the application to function.

The application does not sell personal information or use it for advertising purposes.

## 6. Privacy Rights

Requests concerning personal information or records maintained in Content Manager should be directed to the organisation responsible for those records.

Privacy rights and requests are handled in accordance with applicable privacy laws and organisational policies.

## 7. Changes to This Policy

This Privacy Policy may be updated to reflect changes to the application's functionality, data handling practices, or applicable requirements.
